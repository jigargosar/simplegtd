## What's working (per the report)

- Spec-first, evidence-first workflow: writing requirements down, building blind against them, then treating divergence between independent builds as a signal of spec gaps.
- Empirical verification of Claude Code config itself — A/B-testing `skillOverrides` vs `permissions.deny`, and testing which hooks actually reach context, rather than trusting documentation or claims.
- Redirecting throwaway shell work into reusable Node/TS scripts.

## What's hindering (per the report)

- Claude acts before authorization: guesses paths, starts edits/deletions before approval.
- False verification claims: reporting "verified" or "shown" work that wasn't actually checked, or validating against its own summary instead of the source spec.
- Scope creep on narrow requests (whole-file rewrites for one-line asks).
- Verbose, jargon-heavy responses requiring repeated trimming.
- Most constraints get negotiated mid-session rather than living in CLAUDE.md from the start.

## Features to try (per the report)

- Custom skills for repeated guardrails (scoped-edit, verify-before-claiming, spec-gap-audit).
- A PreToolUse hook to hard-block unscoped recursive greps and blind `git add`/`chezmoi forget`.
- Task agents for parallel exploration/spec audits, with an explicit required output shape.

## New patterns suggested

- Separate the "decide" turn from the "act" turn with an explicit phase boundary in the prompt.
- Require inline CLAIM/EVIDENCE pairs for any status claim; ban "verified/working/done" without pasted output.
- A narrow `/doc` skill restricting doc edits to the named section only.
- A fixed constraints block pasted at the start of multi-step sessions.

## On the horizon (speculative, per the report)

- A `/verify` skill: a clean-context subagent checks each spec requirement against the real build before any "done" claim is allowed.
- Parallel-spike engine: 4 subagents build the same spec independently with zero cross-visibility, a 5th agent diffs them and reports divergences as unresolved spec ambiguities.
- Scope-contract enforcement: Claude declares files/line-range/mode before any Edit/Write, enforced by a hook.
