# Spec

## Shape

- [x] Tasks live in named lists.
- [x] Lists are ordered. Tasks are ordered within their list.

## Capture

- [x] Quick capture.

## Lists

- [x] Add, rename, reorder, collapse, delete.
- [x] New lists go to the bottom.
- [x] A blank name is refused.
- [x] Deleting a list takes its tasks with it.

## Tasks

- [x] Add, tick done, rename, reorder, move to another list, delete.
- [x] New tasks go to the bottom of their list.
- [x] A blank name is refused.
- [x] Done tasks stay where they are, marked.

## Finding things

- [x] Search matches any part of a task's title.
- [x] Show all, only unfinished, or only done.
- [x] Search and filter apply together.

## Keeping your work

- [x] All information is preserved in browser.
- Text you have typed is preserved across a refresh, in every field.
  - Today only the capture box and a new list's name do this.
- [x] First run comes with example lists to show the idea.

## Keyboard

- [x] The whole app can be driven from the keyboard.

## Not doing

- Due dates, tags, notes, subtasks, projects, archiving.
- Drag and drop.
- Multi-select and bulk actions.
- Export.
- Account, sync, sharing.
- Undo.
