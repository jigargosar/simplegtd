# Spec

## Features

- Tasks live in named lists.
- Quick capture.
- Full control of lists: add, rename, reorder, collapse, delete.
- Full control of tasks: add, tick done, rename, reorder, move between lists, delete.
- Search by title.
- Filter to all, unfinished, or done.
- Undo a delete.
- Saves itself. It is there when you come back.
- Text you have typed is preserved across a refresh, in every field.
  - Today only the capture box and a new list's name do this.
- Stays in the browser. No account, no sync, no sharing.
- Starts with example lists.
- Full keyboard control.

## Not doing

- Due dates, tags, notes, subtasks, projects, archiving.
- Drag and drop.
- Multi-select and bulk actions.
- Export.
